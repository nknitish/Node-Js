# What is Express.js?

> **Interview Definition:**
> **Express.js** is a fast, lightweight, and flexible web framework built on top of Node.js. It simplifies the process of building web servers and REST APIs by providing features such as routing, middleware, request/response handling, and error handling.

# 1. What is Express.js?

Express.js is a **minimal web framework** for Node.js.

Node.js provides low-level APIs like:

- `http`
- `https`
- `fs`
- `path`

Express builds on top of these APIs and makes it much easier to build web applications.

Think of it like this:

```text
Node.js
│
├── Runtime Environment
├── Event Loop
├── V8 Engine
└── Core Modules (http, fs, path...)

        │
        ▼

Express.js
│
├── Routing
├── Middleware
├── Request Handling
├── Response Handling
├── Error Handling
└── REST API Development
```

**Simple Analogy**

- **Node.js** is like an engine.
- **Express.js** is like a car built on that engine.

The engine provides power, while the car provides a complete and easier driving experience.

# 2. Why Do We Need Express?

Without Express, creating a simple HTTP server requires handling many low-level details.

Using only Node.js:

```js
import http from "node:http";

const server = http.createServer((req, res) => {
  if (req.url === "/") {
    res.writeHead(200, {
      "Content-Type": "text/plain",
    });

    res.end("Home Page");
  } else if (req.url === "/about") {
    res.end("About Page");
  } else {
    res.statusCode = 404;
    res.end("Page Not Found");
  }
});

server.listen(3000);
```

With Express:

```js
import express from "express";

const app = express();

app.get("/", (req, res) => {
  res.send("Home Page");
});

app.get("/about", (req, res) => {
  res.send("About Page");
});

app.listen(3000);
```

Express reduces boilerplate and makes applications easier to maintain.

# 3. Node.js vs Express.js

| Node.js                 | Express.js                  |
| ----------------------- | --------------------------- |
| JavaScript Runtime      | Web Framework               |
| Executes JavaScript     | Builds web applications     |
| Provides low-level APIs | Provides high-level APIs    |
| Requires manual routing | Built-in routing            |
| Manual request handling | Simplified request handling |
| Manual middleware       | Middleware support          |

# 9. Your First Express Server

```js
import express from "express";

const app = express();

const PORT = 3000;

app.get("/", (req, res) => {
  res.send("Hello Express!");
});

app.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
```

Run:

```bash
node index.js
```

Visit:

```text
http://localhost:3000
```

Output:

```text
Hello Express!
```

# 12. Common Interview Questions

### What is Express.js?

Express.js is a minimal and flexible web framework built on top of Node.js that simplifies building web servers and APIs.

---

### Is Express a web server?

No.

Node.js creates the actual HTTP server. Express is a framework that provides a simpler programming interface for handling requests and responses.

---

### Does Express replace Node.js?

No.

Express depends on Node.js and cannot run without it.

```text
Node.js

↓

Express

↓

Your Application
```

---

### Why is Express so popular?

Because it is:

- Lightweight
- Easy to learn
- Flexible
- Highly extensible through middleware
- Well suited for REST API development

---

### Can Express build REST APIs?

Yes.

Express is one of the most widely used frameworks for building REST APIs in Node.js.

# 14. Interview Answer

> **Express.js is a fast, lightweight, and flexible web framework built on top of Node.js. While Node.js provides the runtime and low-level HTTP APIs, Express simplifies web development by offering features such as routing, middleware, request and response handling, and error handling. It is widely used to build REST APIs and backend services because it reduces boilerplate code and provides a clean, extensible architecture.**
