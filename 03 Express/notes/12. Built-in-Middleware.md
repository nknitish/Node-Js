# Express.js Built-in Middleware

> **Interview Definition:**
> **Built-in middleware** are middleware functions provided by Express out of the box. They perform common tasks such as parsing JSON request bodies, parsing HTML form data, and serving static files without requiring external packages.

# 1. What is Built-in Middleware?

Express includes middleware that can be used without installing additional packages.

Common built-in middleware:

- `express.json()`
- `express.urlencoded()`
- `express.static()`

These middleware handle common web application tasks.

---

# 2. Why Do We Need Built-in Middleware?

Without middleware:

```text
Client

↓

POST Request

↓

Express

↓

req.body

↓

undefined ❌
```

With middleware:

```text
Client

↓

POST Request

↓

express.json()

↓

req.body

↓

Controller
```

The middleware processes the request before it reaches the route handler.

---

# 3. Types of Built-in Middleware

| Middleware             | Purpose                   |
| ---------------------- | ------------------------- |
| `express.json()`       | Parse JSON request bodies |
| `express.urlencoded()` | Parse HTML form data      |
| `express.static()`     | Serve static files        |

# 4. `express.json()`

## What is it?

Parses incoming requests whose body contains JSON.

```js
app.use(express.json());
```

---

## Why do we need it?

Request:

```http
POST /users
Content-Type: application/json
```

Body:

```json
{
  "name": "Nitish",
  "age": 25
}
```

Without:

```js
app.post("/users", (req, res) => {
  console.log(req.body);
});
```

Output:

```js
undefined;
```

With:

```js
import express from "express";

const app = express();

app.use(express.json());

app.post("/users", (req, res) => {
  console.log(req.body);

  res.send("Received");
});
```

Output:

```js
{
    name: "Nitish",
    age: 25
}
```

---

## Internal Flow

```text
Client

↓

JSON Body

↓

express.json()

↓

JavaScript Object

↓

req.body

↓

Controller
```

---

# 5. `express.urlencoded()`

## What is it?

Parses data submitted from HTML forms.

```js
app.use(
  express.urlencoded({
    extended: true,
  }),
);
```

---

## HTML Form

```html
<form method="POST" action="/login">
  <input name="email" />
  <input name="password" />
  <button>Login</button>
</form>
```

Route:

```js
app.post("/login", (req, res) => {
  console.log(req.body);

  res.send("Login");
});
```

Output:

```js
{
    email: "abc@gmail.com",
    password: "123456"
}
```

---

## `extended` Option

```js
express.urlencoded({
  extended: true,
});
```

| Option  | Description                                        |
| ------- | -------------------------------------------------- |
| `true`  | Supports nested objects and richer data structures |
| `false` | Supports only simple key-value pairs               |

Example:

Form data:

```text
user[name]=Nitish
user[age]=25
```

With `extended: true`:

```js
{
    user: {
        name: "Nitish",
        age: "25"
    }
}
```

---

# 6. `express.static()`

## What is it?

Serves static files directly to the client.

Examples:

- Images
- CSS
- JavaScript
- Fonts
- PDFs

---

## Folder Structure

```text
project/

├── public/

│   ├── logo.png

│   ├── style.css

│   ├── app.js

│   └── index.html
```

---

## Register Middleware

```js
app.use(express.static("public"));
```

---

Now these URLs work automatically:

```text
http://localhost:3000/logo.png

http://localhost:3000/style.css

http://localhost:3000/app.js

http://localhost:3000/index.html
```

No route is required.

---

## Internal Flow

```text
Browser

↓

GET /logo.png

↓

express.static()

↓

public/logo.png

↓

Response
```

---

## Multiple Static Directories

```js
app.use(express.static("public"));

app.use(express.static("uploads"));
```

Both folders are searched for matching files.

---

## Virtual Prefix

```js
app.use("/assets", express.static("public"));
```

Now:

```text
http://localhost:3000/assets/logo.png
```

maps to:

```text
public/logo.png
```

---

# 7. Middleware Execution Flow

```text
Client

↓

Request

↓

express.json()

↓

express.urlencoded()

↓

express.static()

↓

Route Handler

↓

Response
```

Depending on the request, one or more middleware may process it before the route handler runs.

---

# 8. Real-world Example

```js
import express from "express";

const app = express();

app.use(express.json());

app.use(
  express.urlencoded({
    extended: true,
  }),
);

app.use(express.static("public"));

app.post("/users", (req, res) => {
  console.log(req.body);

  res.status(201).json(req.body);
});

app.listen(3000);
```

Execution:

```text
POST /users

↓

express.json()

↓

req.body

↓

Controller

↓

Response
```

---

# 9. Best Practices

✅ Register middleware before routes.

```js
app.use(express.json());

app.use(express.urlencoded({ extended: true }));

app.use(express.static("public"));

app.use("/users", userRouter);
```

---

❌ Incorrect Order

```js
app.post("/users", controller);

app.use(express.json());
```

`req.body` may not be populated because the parser runs after the route.

# 10. Common Interview Questions

### What is built-in middleware?

Middleware provided directly by Express without installing external packages.

---

### Why is `express.json()` needed?

To parse JSON request bodies and populate `req.body`.

---

### What does `express.urlencoded()` do?

It parses URL-encoded form data submitted by HTML forms.

---

### What is the difference between `express.json()` and `express.urlencoded()`?

| `express.json()`     | `express.urlencoded()`       |
| -------------------- | ---------------------------- |
| Parses JSON payloads | Parses URL-encoded form data |
| Used for APIs        | Used for HTML forms          |

---

### What does `express.static()` do?

It serves static files such as images, CSS, JavaScript, and HTML directly from a directory.

---

### Should middleware be registered before routes?

Yes. Middleware that prepares the request (such as body parsers) should be registered before routes that depend on it.

# 12. Interview Answer

> **Express provides several built-in middleware functions for common web development tasks. `express.json()` parses incoming JSON request bodies and makes the data available on `req.body`. `express.urlencoded()` parses URL-encoded form submissions, commonly used with HTML forms. `express.static()` serves static assets such as images, CSS, JavaScript, and HTML files directly from a directory. These middleware are typically registered near the top of the application so requests are processed correctly before reaching route handlers.**
