# Express.js Application and Routing

> **Interview Definition:**
> An **Express Application** is the main object created by calling `express()`. It acts as the central application that receives HTTP requests, applies middleware, matches routes, and sends responses. **Routing** is the process of mapping incoming HTTP requests (URL + HTTP method) to specific handler functions.

# 1. What is an Express Application?

The application object is created by calling:

```js
import express from "express";

const app = express();
```

`app` represents your entire web application.

It is responsible for:

- Receiving HTTP requests
- Registering middleware
- Defining routes
- Sending responses
- Starting the server

Think of it as the **heart of your Express application**.

# 2. What is Routing?

Routing is the process of deciding **which code should execute** when a request arrives.

Example:

```text
GET /

↓

Home Page
```

```text
GET /users

↓

Users List
```

```text
POST /users

↓

Create User
```

Every route has:

- HTTP Method
- URL Path
- Callback Function

---

# 3. Why Do We Need Routing?

Imagine every request is handled in one function.

```text
Request

↓

if /users

↓

if /products

↓

if /orders

↓

if /login

↓

if /logout

↓

1000 more conditions...
```

This becomes difficult to maintain.

Express solves this using routing.

```text
/users

↓

Users Route


/products

↓

Products Route


/orders

↓

Orders Route
```

# 6. Basic Routing

```js
  res.send("Home Page");

```



# 7. Route Methods

| Method | Purpose               |
| ------ | --------------------- |
| GET    | Read data             |
| POST   | Create data           |
| PUT    | Replace/update data   |
| PATCH  | Partially update data |
| DELETE | Delete data           |

Example:

```js

  res.send("User Updated");
```

# 8. Route Parameters

Dynamic values inside URLs.

Example:

```text
/users/25
```

Route:

```js
app.get("/users/:id", (req, res) => {
  console.log(req.params);

  res.send(req.params.id);
});
```

Output

```text
25
```

`req.params`

```js
{
  id: "25";
}
```

Multiple parameters:

```js
app.get("/users/:userId/posts/:postId", (req, res) => {
  console.log(req.params);
});
```

Output:

```js
{
    userId: "10",
    postId: "5"
}
```

---

# 9. Query Parameters

Example URL

```
/users?page=2&limit=10
```

Access:

```js
app.get("/users", (req, res) => {
  console.log(req.query);
});
```

Output

```js
{
    page: "2",
    limit: "10"
}
```

Difference:

| Route Params         | Query Params    |
| -------------------- | --------------- |
| Required part of URL | Optional        |
| `/users/:id`         | `/users?page=2` |

# 10. Route Order Matters

Express checks routes **from top to bottom**.

Wrong:

```js
app.get("/:id", () => {});

app.get("/about", () => {});
```

Request:

```
/about
```

Matches:

```text
:id
```

Correct:

```js
app.get("/about", () => {});

app.get("/:id", () => {});
```

Always place **specific routes before dynamic routes**.

# 11. Multiple Route Handlers

```js
function log(req, res, next) {
```

```text

↓

↓
```

# 12. Express Router

Instead of writing every route inside `index.js`.

Bad:

```text
index.js

↓

500 routes
```

Better:

```text
routes/

├── users.js

├── products.js

├── auth.js
```

users.js

```js
import express from "express";

const router = express.Router();

router.get("/", (req, res) => {
  res.send("All Users");
});

export default router;
```

index.js

```js
import express from "express";

import usersRouter from "./routes/users.js";

const app = express();

app.use("/users", usersRouter);
```

Request

```
GET /users
```

Output

```
All Users
```

# 14. Common Interview Questions

### What is an Express Application?

The object returned by `express()` that represents the entire web application.

---

### What is Routing?

The process of mapping an HTTP request (method + path) to a handler function.

---

### Difference between Route Params and Query Params?

| Route Params | Query Params    |
| ------------ | --------------- |
| `/users/:id` | `/users?page=1` |
| Required     | Optional        |
| `req.params` | `req.query`     |

---

### Why use Express Router?

To split routes into separate modules, improving readability, maintainability, and scalability.

---

### Does route order matter?

Yes.

Express matches routes in the order they are registered.

# 16. Interview Answer

> **An Express application is created by calling `express()`, which returns an application object responsible for handling HTTP requests, middleware, routing, and responses. Routing is the mechanism that maps an incoming HTTP request, identified by its method and URL path, to a specific handler function. Express supports route methods such as `GET`, `POST`, `PUT`, `PATCH`, and `DELETE`, and provides `express.Router()` to organize routes into reusable modules. Route parameters (`req.params`) are used for dynamic URL segments, while query parameters (`req.query`) are used for optional filtering, sorting, and pagination.**
