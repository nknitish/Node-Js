# Express.js Response Object (`res`)

> **Interview Definition:**
> The **Response Object (`res`)** is an object provided by Express that represents the outgoing HTTP response. It is used to send data, JSON, files, status codes, headers, redirects, cookies, and other information back to the client.

# 1. What is the Response Object?

Whenever Express receives an HTTP request, it creates a **Response Object (`res`)**.

Its job is to send a response back to the client.

```text
Browser

↓

Request

↓

Express

↓

res

↓

HTTP Response

↓

Browser
```

Every route receives:

```js
(req, res);
```

- `req` → Incoming request
- `res` → Outgoing response

---

# 2. Request → Response Lifecycle

```text
Client

↓

HTTP Request

↓

Express

↓

Middleware

↓

Route Handler

↓

Response Object (res)

↓

HTTP Response

↓

Client
```

A request should normally result in **one response**.

# 3. Creating a Response

```js
import express from "express";

const app = express();

app.get("/", (req, res) => {
  res.send("Hello Express");
});

app.listen(3000);
```

Visit:

```
GET /
```

Output:

```
Hello Express
```

# 4. Common Response Methods

| Method             | Purpose                                 |
| ------------------ | --------------------------------------- |
| `res.send()`       | Send text, HTML, object, or buffer      |
| `res.json()`       | Send JSON                               |
| `res.status()`     | Set HTTP status code                    |
| `res.sendStatus()` | Set status and send its default message |
| `res.redirect()`   | Redirect client                         |
| `res.sendFile()`   | Send a file                             |
| `res.download()`   | Download a file                         |
| `res.set()`        | Set response headers                    |
| `res.cookie()`     | Set cookies                             |

---

# 5. `res.send()`

The most commonly used response method.

### Send Text

```js
app.get("/", (req, res) => {
  res.send("Hello World");
});
```

---

### Send HTML

```js
app.get("/", (req, res) => {
  res.send("<h1>Hello</h1>");
});
```

---

### Send an Object

```js
app.get("/", (req, res) => {
  res.send({
    name: "Nitish",
  });
});
```

Express automatically converts objects to JSON.

---

# 6. `res.json()`

Sends JSON data.

```js
app.get("/users", (req, res) => {
  res.json({
    id: 1,
    name: "Nitish",
  });
});
```

Response:

```json
{
  "id": 1,
  "name": "Nitish"
}
```

### `res.send()` vs `res.json()`

| `res.send()`                  | `res.json()`                |
| ----------------------------- | --------------------------- |
| Can send different data types | Intended for JSON responses |
| Text, HTML, Buffer, Object    | JSON only                   |

For APIs, `res.json()` is usually the clearer choice.

---

# 7. `res.status()`

Sets the HTTP status code.

```js
app.get("/", (req, res) => {
  res.status(200);

  res.send("Success");
});
```

Usually written as:

```js
res.status(200).send("Success");
```

---

### Return JSON

```js
res.status(201).json({
  message: "User Created",
});
```

---

# 8. `res.sendStatus()`

Sets the status code and sends its standard text response.

```js
res.sendStatus(404);
```

Response:

```text
404 Not Found
```

Another example:

```js
res.sendStatus(500);
```

Response:

```text
500 Internal Server Error
```

---

# 9. `res.redirect()`

Redirects the client to another URL.

```js
app.get("/home", (req, res) => {
  res.redirect("/");
});
```

You can also redirect to external URLs:

```js
res.redirect("https://example.com");
```

---

# 10. `res.sendFile()`

Send a file to the client.

```js
import path from "node:path";

res.sendFile(path.join(process.cwd(), "public", "index.html"));
```

Common use cases:

- HTML pages
- PDFs
- Images

---

# 11. `res.download()`

Forces the browser to download a file.

```js
res.download("./files/report.pdf");
```

The browser typically prompts the user to save the file.

---

# 12. `res.set()`

Sets response headers.

```js
res.set("Content-Type", "application/json");
```

Multiple headers:

```js
res.set({
  "X-App": "Express Demo",
  "Cache-Control": "no-store",
});
```

---

# 13. `res.cookie()`

Set a cookie.

Install middleware if you also want to read cookies:

```bash
npm install cookie-parser
```

Example:

```js
res.cookie("username", "Nitish");
```

With options:

```js
res.cookie("token", "abc123", {
  httpOnly: true,
  maxAge: 60 * 60 * 1000,
});
```

---

# 14. Method Chaining

Express methods are chainable.

Instead of:

```js
res.status(200);

res.json({
  success: true,
});
```

Use:

```js
res.status(200).json({
  success: true,
});
```

Another example:

```js
res.status(404).send("User Not Found");
```

# 18. Common Interview Questions

### What is `res`?

The Express Response Object used to send an HTTP response to the client.

---

### Difference between `res.send()` and `res.json()`?

| `res.send()`                | `res.json()` |
| --------------------------- | ------------ |
| Can send various data types | Sends JSON   |
| Text, HTML, Buffer, Object  | JSON only    |

---

### Why use `res.status(201)` after creating a resource?

HTTP **201 Created** indicates that a new resource has been successfully created.

---

### What happens if you don't send a response?

The request remains open until it times out or another part of the application ends it.

---

### Can you send two responses?

No.

This causes an error such as:

```text
Error: Cannot set headers after they are sent to the client
```

# 20. Interview Answer

> **The Express Response Object (`res`) represents the outgoing HTTP response. It provides methods for sending data, JSON, files, redirects, headers, cookies, and HTTP status codes back to the client. Common methods include `res.send()`, `res.json()`, `res.status()`, `res.redirect()`, and `res.sendFile()`. These methods are chainable, allowing patterns like `res.status(200).json(data)`. Each request should normally produce a single response, and attempting to send multiple responses results in an error.**
