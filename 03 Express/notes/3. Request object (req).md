# Express.js Request Object (`req`)

> **Interview Definition:**
> The **Request Object (`req`)** is an object provided by Express that represents the incoming HTTP request. It contains all the information sent by the client, such as URL, HTTP method, headers, query parameters, route parameters, request body, cookies, IP address, and more.

# 1. What is the Request Object?

Whenever a client sends an HTTP request to your Express server, Express creates a **Request Object**.

Example:

```text
Browser

↓

GET /users/10?page=2

↓

Express

↓

req
```

The `req` object contains everything about that request.

# 3. Creating a Request

```js
import express from "express";

const app = express();

app.get("/", (req, res) => {
  console.log(req);

  res.send("Hello");
});

app.listen(3000);
```

Every route handler receives:

```js
(req, res);
```

- `req` → Incoming request
- `res` → Outgoing response

# 4. Common Request Properties

| Property          | Description                   |
| ----------------- | ----------------------------- |
| `req.params`      | Route parameters              |
| `req.query`       | Query parameters              |
| `req.body`        | Request body                  |

# 5. Route Parameters (`req.params`)

Dynamic values in the URL.

Route:

```js
app.get("/users/:id", (req, res) => {
  console.log(req.params);

  res.send(req.params.id);
});
```

Request:

```http
GET /users/25
```

Output:

```js
{
  id: "25";
}
```

Multiple Parameters:

```js
app.get("/users/:userId/orders/:orderId", (req, res) => {
  console.log(req.params);
});
```

Request:

```http
GET /users/5/orders/99
```

Output:

```js
{
  userId: "5",
  orderId: "99"
}
```

---

# 6. Query Parameters (`req.query`)

Used for filtering, sorting, pagination, and searching.

Request:

```http
GET /products?page=2&limit=10&sort=price
```

Route:

```js
app.get("/products", (req, res) => {
  console.log(req.query);
});
```

Output:

```js
{
  page: "2",
  limit: "10",
  sort: "price"
}
```

---

# Route Params vs Query Params

| Route Params | Query Params    |
| ------------ | --------------- |
| `/users/:id` | `/users?page=2` |
| Required     | Optional        |
| `req.params` | `req.query`     |

# 7. Request Body (`req.body`)

Used with:

- POST
- PUT
- PATCH

Enable JSON parsing:

```js
app.use(express.json());
```

Route:

```js
app.post("/users", (req, res) => {
  console.log(req.body);

  res.send("User Created");
});
```

Request Body:

```json
{
  "name": "Nitish",
  "age": 25
}
```

Output:

```js
{
    name: "Nitish",
    age: 25
}
```

Without `express.json()`:

```js
req.body;
```

will usually be:

```js
undefined;
```

for JSON payloads.

# 8. Request Headers (`req.headers`)

Headers contain metadata.

Request:

```http
GET /users

Authorization: Bearer token

Content-Type: application/json
```

Route:

```js
app.get("/users", (req, res) => {
  console.log(req.headers);
});
```

Access a single header:

```js
console.log(req.headers.authorization);
```

or

```js
console.log(req.get("Authorization"));
```

# 11. Client IP Address

```js
app.get("/", (req, res) => {
  console.log(req.ip);
});
```

Output:

```text
::1
```

or

```text
127.0.0.1
```

When behind proxies (e.g., Nginx or a cloud load balancer), you may need to configure Express to trust the proxy to obtain the original client IP.

# 12. Cookies

Install middleware:

```bash
npm install cookie-parser
```

Use:

```js
import cookieParser from "cookie-parser";

app.use(cookieParser());

app.get("/", (req, res) => {
  console.log(req.cookies);
});
```

# 14. Real-world Example

```js
app.post("/login", (req, res) => {
  console.log(req.body.email);

  console.log(req.body.password);

  console.log(req.ip);

  console.log(req.headers);

```

Request:

```http
POST /login

Content-Type: application/json
```

Body:

```json
{
  "email": "abc@gmail.com",
  "password": "1234"
}
```

Flow:

```text
Client

↓

HTTP Request

↓

req.body

↓

Controller

↓

Database

↓

Response
```

# 15. Common Interview Questions

### What is `req`?

The Express Request Object representing the incoming HTTP request.

---

### Difference between `req.params` and `req.query`?

| `req.params`    | `req.query`  |
| --------------- | ------------ |
| Route variables | Query string |
| Required        | Optional     |

---

### Why is `req.body` undefined?

Because middleware such as:

```js
app.use(express.json());
```

has not been added (for JSON requests).

---

### Where do headers come from?

They are sent by the client as part of the HTTP request and are available through `req.headers` or `req.get()`.

---

### What is `req.ip`?

The client's IP address as seen by Express. Behind proxies, additional configuration may be required to obtain the original client IP.

# 17. Interview Answer

> **The Express Request Object (`req`) represents the incoming HTTP request. It contains all information sent by the client, including route parameters (`req.params`), query parameters (`req.query`), request body (`req.body`), headers (`req.headers`), HTTP method (`req.method`), URL information (`req.url`, `req.path`, `req.originalUrl`), client IP (`req.ip`), and cookies (`req.cookies` when cookie middleware is used). It is passed to every route handler and middleware, allowing the application to read request data and process it before generating a response.**
