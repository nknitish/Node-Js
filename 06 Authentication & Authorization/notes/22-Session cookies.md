# Session Cookies

> **Interview Definition:**  
> A **Session Cookie** is a cookie that stores the **Session ID** generated by the server. It is used to identify a user's session across multiple HTTP requests. Unlike JWT cookies that store the entire token, a Session Cookie stores only a unique Session ID, while the actual session data remains on the server.

# 1. What are Session Cookies?

When a user logs in,

the server creates a session.

Example

```text
Server

↓

Session

↓

Session ID

↓

Cookie

↓

Browser
```

The cookie usually looks like

```text
connect.sid=s%3Aabc123xyz...
```

The browser stores **only the Session ID**.

---

# 2. Why Do We Need Session Cookies?

HTTP is stateless.

Example

```text
Request 1

↓

Login

↓

User Authenticated
```

Next request

```text
Request 2

↓

Who is this user?
```

Without Session Cookies,

the server doesn't know.

With Session Cookies

```text
Request

↓

Session ID

↓

Find Session

↓

Authenticated
```

# 5. Session Cookie vs Regular Cookie

| Regular Cookie                | Session Cookie                       |
| ----------------------------- | ------------------------------------ |
| Stores any data               | Stores Session ID                    |
| Can be created manually       | Usually created by `express-session` |
| May contain preferences       | Identifies user session              |
| Doesn't require server lookup | Requires server lookup               |

---

# 6. Session Cookie vs JWT Cookie

| Session Cookie                 | JWT Cookie                    |
| ------------------------------ | ----------------------------- |
| Stores Session ID              | Stores JWT                    |
| Session data on server         | User data inside JWT          |
| Stateful                       | Stateless                     |
| Server performs session lookup | Server verifies JWT signature |
| Requires Session Store         | Doesn't require Session Store |

# 7. express-session & Session Cookies

Basic Setup

```javascript
import session from "express-session";

app.use(
  session({
    secret: process.env.SESSION_SECRET,

    resave: false,

    saveUninitialized: false,

    cookie: {
      httpOnly: true,

      secure: true,

      sameSite: "lax",

      maxAge: 30 * 60 * 1000,
    },
  }),
);
```

# 8. Session Cookie Attributes

Production configuration

```javascript
cookie: {

    httpOnly: true,

    secure: true,

    sameSite: "lax",

    maxAge: 30 * 60 * 1000

}
```

Meaning

| Attribute | Purpose                   |
| --------- | ------------------------- |
| HttpOnly  | Prevent JavaScript access |
| Secure    | HTTPS only                |
| SameSite  | Reduce CSRF attacks       |
| maxAge    | Cookie expiration         |

# 13. Interview Answer

> **A Session Cookie is an HTTP cookie that stores a unique Session ID generated by the server. When a user logs in, the server creates a session, stores the user's data in a session store such as Redis, and sends the Session ID to the browser inside a cookie, typically named `connect.sid`. The browser automatically includes this cookie with every subsequent request. The server uses the Session ID to retrieve the corresponding session data and authenticate the user. Session Cookies usually include security attributes such as `HttpOnly`, `Secure`, `SameSite`, and an expiration time to improve security.**

# ⭐ Most Asked Interview Questions

### Q1. Does the Session Cookie contain user information?

**No.**

Many beginners think:

```text
Cookie

↓

{

userId:123

}
```

This is incorrect.

Instead

```text
Cookie

↓

connect.sid

↓

abc123
```

The server uses this Session ID to look up the user's session.

---

### Q2. Why is storing only the Session ID safer?

If the cookie contained the entire user object,

users could inspect or modify it.

Instead

```text
Browser

↓

Session ID

↓

Server

↓

User Data
```

Sensitive information never leaves the server.

---

### Q3. Why is `connect.sid` important?

It is the default cookie name created by `express-session`.

Example

```http
Cookie:

connect.sid=s%3Aabc123...
```

The value uniquely identifies the user's session.

---

### Q4. What happens if the Session Cookie expires?

```text
Session Cookie

↓

Expired

↓

Browser Stops Sending Cookie

↓

Server Cannot Find Session

↓

401 Unauthorized

↓

User Must Login Again
```

This is why session expiration directly affects how long a user remains logged in.
