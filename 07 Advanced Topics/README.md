# 07 Advanced Topics

This section is built as a pnpm workspace for independent learning modules. Each subfolder is a standalone Node.js example with its own package.json and notes folder.

## Modules

1. Validation & Error Handling
2. Security Best Practices
3. File Uploads & Static Files
4. Cache & Redis
5. Testing & API Quality
6. Background Jobs & Real-Time
7. Deployment & Performance
8. Prisma & Database ORM

## Run a module

```bash
cd "07 Advanced Topics/01 Validation & Error Handling"
pnpm install
pnpm start
```

## Learning flow

- Start with validation and error handling
- Move to security
- Learn uploads and files
- Use Redis cache for performance
- Add testing for confidence
- Add real-time features and jobs
- Use Prisma for database access
- Finish with deployment and observability
